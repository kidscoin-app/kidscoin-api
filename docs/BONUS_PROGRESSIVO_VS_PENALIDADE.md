## 🧠 BEHAVIORAL ECONOMICS (Teoria)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEITO 1: LOSS AVERSION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINIÇÃO:
Perder algo dói 2X mais que ganhar mesma coisa

EXEMPLO:
Perder R$ 10 = Dor 10
Ganhar R$ 10 = Prazer 5
→ Assimétrico!

DESCOBERTA:
Daniel Kahneman (Nobel Prize)

APLICAÇÃO KIDSCOIN:

MODELO PENALIDADE (Loss Frame):
"Se sacar antes 7 dias, PERDE 50% juros"
→ Criança foca na PERDA
→ Dor psicológica alta
→ Ansiedade, frustração
→ "Não quero perder!" (negativo)

MODELO BÔNUS (Gain Frame):
"Se esperar 15 dias, GANHA +20% juros!"
→ Criança foca no GANHO
→ Prazer antecipatório
→ Motivação, excitement
→ "Quero ganhar mais!" (positivo)

RESULTADO:
Gain frame > Loss frame para motivação! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEITO 2: FRAMING EFFECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINIÇÃO:
Como você apresenta informação afeta decisão

EXEMPLO CLÁSSICO:
"90% chance sobreviver cirurgia"
vs
"10% chance morrer cirurgia"

MESMO fato, frames diferentes:
→ Positive frame: Mais aceitação
→ Negative frame: Mais medo

APLICAÇÃO KIDSCOIN:

NEGATIVE FRAME (Penalidade):
"⚠️ Saque antes 7 dias: Perde 50% juros"
→ Ameaçador
→ Criança se sente punida
→ "App me pune!" (bad feeling)

POSITIVE FRAME (Bônus):
"🎉 Espere 15 dias: Ganhe +20% juros!"
→ Recompensador
→ Criança se sente incentivada
→ "App me recompensa!" (good feeling)

RESULTADO:
Positive frame = Melhor UX + Motivação! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEITO 3: PROGRESS PSYCHOLOGY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINIÇÃO:
Progresso visível = Motivação contínua

EXEMPLO:
LinkedIn profile strength bar:
"40% completo → 60% → 80% → 100%!"
→ Cada step motivador

APLICAÇÃO KIDSCOIN:

MODELO PENALIDADE:
Apenas 1 threshold (7 dias)
→ Binary: Penalty ou não
→ Não progressivo

MODELO BÔNUS PROGRESSIVO:
Múltiplos tiers:
7d → 15d → 30d → 60d → 90d
→ Sempre próximo milestone
→ "Faltam 3 dias para +20%!"

RESULTADO:
Progressão > Binary para engagement! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEITO 4: ENDOWMENT EFFECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINIÇÃO:
Valorizar mais o que JÁ temos

EXEMPLO:
Caneca que você ganhou: Vale $7
Mesma caneca comprar: Vale $3
→ Ownership aumenta valor

APLICAÇÃO KIDSCOIN:

MODELO PENALIDADE:
Juros já "ganhos" mas podem ser "perdidos"
→ Endowment effect FORTE
→ Perder juros acumulados = DOR ALTA
→ "Esses juros eram MEUS!" (frustração)

MODELO BÔNUS:
Juros base garantidos, bônus adicional possível
→ Juros base = secured (endowment satisfeito)
→ Bônus = upside (ganho potencial)
→ "Ganhei base + posso ganhar mais!" (positivo)

RESULTADO:
Bônus protege endowment, menos dor! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONCEITO 5: REACTANCE THEORY (Crianças!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINIÇÃO:
Quando sentimos liberdade ameaçada, resistimos

EXEMPLO CLÁSSICO (Crianças):
Pai: "NÃO pode comer doce!"
Criança: Quer doce MAIS ainda (reactance)

APLICAÇÃO KIDSCOIN:

MODELO PENALIDADE:
"NÃO pode sacar antes 7 dias ou perde!"
→ Restrição percebida
→ Reactance: "Quero sacar AGORA!"
→ Comportamento oposto desejado

MODELO BÔNUS:
"PODE sacar quando quiser, mas esperar = bônus!"
→ Liberdade preservada
→ Sem reactance
→ Decisão voluntária ("Vou esperar!")

RESULTADO:
Bônus respeita autonomia criança! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RESUMO BEHAVIORAL ECONOMICS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MODELO BÔNUS PROGRESSIVO ganha em:

1. ✅ Loss Aversion (gain frame, não loss)
2. ✅ Framing Effect (positive, não negative)
3. ✅ Progress Psychology (tiers múltiplos)
4. ✅ Endowment Effect (protege "meu")
5. ✅ Reactance Theory (liberdade preservada)

MODELO PENALIDADE perde em todos! ❌

CIÊNCIA CLARA: Bônus > Penalidade! 🧠✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

function withdraw(user_id, amount):
  deposits = get_deposits_fifo(user_id)
  
  remaining = amount
  total_received = 0
  breakdown = []
  
  for deposit in deposits:
    if remaining <= 0:
      break
    
    # Days held
    days = (today - deposit.deposit_date).days
    
    # Calculate base interest
    principal = deposit.amount_principal
    total_value = principal × (1.01 ^ days)
    base_interest = total_value - principal
    
    # Apply bonus multiplier
    multiplier = getBonusMultiplier(days)
    final_interest = base_interest × multiplier
    
    # Total this deposit
    deposit_total = principal + final_interest
    
    # How much to withdraw from this
    withdrawal_amount = min(remaining, deposit_total)
    
    # Breakdown
    tier = getTierName(days)
    breakdown.append({
      'deposit_id': deposit.id,
      'days_held': days,
      'tier': tier,
      'multiplier': multiplier,
      'principal': min(withdrawal_amount, principal),
      'base_interest': base_interest,
      'final_interest': final_interest,
      'received': withdrawal_amount
    })
    
    # Update
    remaining -= withdrawal_amount
    total_received += withdrawal_amount
    
    # Update deposit
    if withdrawal_amount >= deposit_total:
      deposit.status = 'withdrawn'
    else:
      # Partial withdrawal logic
      ...
  
  # Add to wallet
  user.wallet_balance += total_received
  
  return {
    'total_received': total_received,
    'breakdown': breakdown
  }
